TURAN FM — плейлист для дороги в колледж Туран

Файлы:
- index.html — главная страница плейлиста
- style.css — оформление
- reverie.mp3 — присланный трек IVOXYGEN — Reverie

Для публикации на GitHub Pages:
1. Создайте на GitHub публичный репозиторий (например, turan-playlist).
2. Загрузите в корень репозитория все три файла.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch, Branch: main, Folder: / (root), затем Save.
5. Через некоторое время GitHub покажет ссылку на опубликованный сайт.

Музыка запускается кнопкой Play: браузеры обычно блокируют автозапуск со звуком.
